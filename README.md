# DominionDev

A tour, not a resume.

Personal site for [DominionDev](https://github.com/dominionthedev). Isolation, motion, color, and the editor I refuse to leave.

## Run

```sh
npm install
npm run dev
```

Build:

```sh
npm run build
npm run preview
```

## Keyboard

`j` / `k` or arrows move between stages. Space goes forward.

## Stack

Astro, Tailwind, Maple Mono.
